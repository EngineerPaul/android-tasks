# ТЗ. Приложение Tasks

Документ описывает приложение целиком. Открытых вопросов нет, его можно отдать в разработку как есть.

Пользователь сам приложение не собирает и не настраивает сервисы. Единственное, что он делает руками, — ставит Android Studio, запускает проект и выдаёт разрешения на уведомления. Эти шаги разработчик оформляет отдельным файлом `SETUP.md` (раздел 12).

---

## 1. Назначение

Tasks — записная книжка задач на один телефон. Задачи лежат списками. Списки называются окнами и листаются влево-вправо. Одно окно особое: у задач в нём есть срок, и телефон сам показывает уведомление в этот момент.

Приложение работает без интернета. Учётной записи нет. Сервера нет. Данные лежат в закрытой памяти приложения и никуда не отправляются.

## 2. Платформа и стек

- Язык: Kotlin.
- Интерфейс: Jetpack Compose, Material 3, одна тёмная тема.
- Экран: одна Activity, внутри неё маршруты Compose Navigation.
- Хранение: Room (SQLite) во внутренней памяти приложения.
- Уведомления: локальные, `AlarmManager` (точный будильник) и `NotificationManager`. После перезагрузки телефона будильники восстанавливаются по `BOOT_COMPLETED`.
- Порядок задач и окон: библиотека перетаскивания для Compose (`sh.calvin.reorderable`) и `HorizontalPager`.
- Шрифт Manrope с кириллицей лежит в `res/font` и грузится с диска телефона.
- Минимальная версия Android: 8.0 (API 26). Сборка и целевая версия — актуальный стабильный SDK на момент разработки.
- В манифесте нет разрешения `INTERNET`. Сетевых библиотек нет.

Уведомление в заданный час ставит само приложение. Android будит его по будильнику, и оно кладёт запись в шторку через `NotificationManager`. Сервера и Firebase нет: срок хранится только в базе на телефоне.

## 3. Дизайн

Тёмная «ночная» тема. Фон холодный и глубокий, акцент тёплый янтарный, как лампа на тёмном столе. Текст и кнопки светлее фона и читаются без усилия. Карточки задач похожи на отдельные облака и не сливаются друг с другом.

### 3.3. Логотип

Знак — короткий список дел, верхний пункт уже выполнен. Облака в знаке нет.

Иконка запуска (adaptive icon), рисунок в безопасной зоне по центру:

- фон сплошной `#12151C`;
- три строки сверху вниз, зазор между строками 8dp;
- у каждой строки слева скруглённый квадрат 16×16dp, радиус 4dp;
- верхний квадрат залит `#F0C674`, внутри галочка `#12151C` толщиной 2.5dp со скруглёнными концами;
- средний и нижний квадраты без заливки, обводка 2dp цветом `#F0C674`;
- справа от каждого квадрата зазор 8dp и скруглённая плашка высотой 6dp, радиус 3dp, по вертикали по центру квадрата;
- верхняя плашка длиной 36dp, цвет `#F0C674`;
- средняя 28dp и нижняя 20dp, цвет `#F0C674` с прозрачностью 50%.

Так на маленьком значке читается список: одно дело закрыто, два ещё открыты.

На экране «Настройки» сверху тот же знак 28dp и слово Tasks. В рабочей шапке со списками логотипа нет, чтобы поместились окна.

Имя на рабочем столе телефона: **Tasks**. Подпись латиницей, как есть, без перевода.

### 3.4. Общие правила интерфейса

- Сейчас одна тема, тёмная. В настройках есть строка «Тема» со значением «Тёмная» обычным текстом, без переключателя. Все цвета экранов берутся из одной палитры в `ui/theme`, в компоновках сырых HEX нет. Новая тема в будущем — вторая палитра в том же месте и выбор в одной точке. Экраны из-за этого не переписываются.
- Сейчас язык интерфейса русский. В настройках есть строка «Язык» со значением «Русский» обычным текстом, без переключателя. Все подписи лежат в `res/values/strings.xml` и читаются через ресурсы, в том числе заголовки «Задача %1$d» и «Напоминание %1$d». Английский в будущем — файл `res/values-en/strings.xml` с теми же ключами. Названия групп и текст заметок — данные человека, они не переводятся. Имя на рабочем столе остаётся Tasks.
- Кнопки и строки нажимаются областью не меньше 48dp.
- Экран рисуется edge-to-edge, системные иконки светлые.
- Список задач по ширине равен экрану и влево-вправо не ездит. В списке название обрезается на 50 символах многоточием. В базе хранится до 500 символов.
- Список задач прокручивается по вертикали, когда строк больше, чем помещается.

## 4. Данные

База Room. Две таблицы.

**Окно**

| Поле | Смысл |
| --- | --- |
| id | ключ |
| name | название на кнопке навигации |
| kind | `LIST` или `SCHEDULED` |
| sortOrder | порядок слева направо |
| builtIn | исходное окно, его нельзя удалить |

**Задача**

| Поле | Смысл |
| --- | --- |
| id | ключ |
| groupId | окно |
| title | название |
| description | описание, может быть пустым |
| rating | целое от `RatingScale.MIN` до `RatingScale.MAX` |
| sortOrder | порядок сверху вниз. В исходном окне «Запланированные» на экран не влияет: там порядок по дате |
| nextFireAt | ближайший момент уведомления, миллисекунды, только для окна со сроком |
| repeatEveryDays | период в днях; пусто — один раз |
| notifiedOnce | для задачи без повтора: уведомление уже показано |
| dueUnseen | напоминание наступило, а человек его ещё не открывал |

При первом запуске создаются четыре окна в таком порядке:

1. Сегодня — `LIST`, исходное
2. Неделя — `LIST`, исходное
3. Месяц — `LIST`, исходное
4. Запланированные — `SCHEDULED`, исходное

«Сегодня», «Неделя» и «Месяц» — обычные списки. Задача лежит в том окне, куда её положили, и сама по дате никуда не переезжает. Дату и время человек указывает в окнах вида `SCHEDULED`: во встроенных «Запланированных» и в группах со сроком, которые он создал в настройках. В обычных списках этих полей нет.

В полосе навигации слева прокручиваются обычные списки и созданные группы со сроком. Справа приклеены две иконки, их место не меняется: «Запланированные» и «Настройки». «Настройки» окном задач не являются и в базе списком не хранятся.

Часовой пояс — местный часовой пояс телефона. В базе лежит момент времени в миллисекундах.

## 5. Навигация

Сверху постоянная полоса.

Слева направо полоса делится на две части. Левая прокручивается и содержит обычные окна и созданные группы со сроком, в порядке `sortOrder`. Правая не прокручивается и всегда видна: иконка часов «Запланированные» 48dp, затем иконка шестерёнки «Настройки» 48dp. Подписи у этих двух иконок в полосе нет. Для чтения с экрана у иконки часов остаётся название окна.

- Обычное окно выглядит как вкладка с подписью. Активная вкладка — светлый текст и янтарная линия снизу 2dp. Неактивная — цвет `#8E887F`.
- Созданная группа со сроком — такая же вкладка, но перед именем стоит та же иконка часов, 16dp, цветом подписи. По ней видно, что у задач в этом окне есть дата.
- «Запланированные» — только иконка часов, приклеена справа и в прокрутке вкладок не едет. В покое обводка и значок `#F0C674`. Когда это окно открыто, кнопка залита `#F0C674`, значок `#1A1408`.
- «Настройки» — шестерёнка, приклеена справа от часов. В перестановке окон не участвует. На экране настроек шестерёнка янтарная, в покое `#F6F3EC`.

На экране списка и на экране настроек в полосе выделен ровно один пункт — то окно или экран настроек, который сейчас открыт. На экране заметки и напоминания не выделен ни один пункт. Обычное активное окно отличается светлым текстом `#F6F3EC` и янтарной линией снизу. Активные «Запланированные» залиты `#F0C674` с тёмным значком. Активные «Настройки» — янтарная шестерёнка. Остальные пункты в этот момент выглядят невыбранными. Выделение переезжает вместе с открытым экраном: после нажатия на пункт, после свайпа между окнами и после переноса задачи в соседний список. Если открытая вкладка уехала за край левой части, эта часть доскролливается так, чтобы вкладка была видна. Иконки часов и шестерёнки за край не уезжают.

Прокручивается только левый ряд вкладок. Правая пара остаётся на месте.

Жест влево или вправо по области задач только листает окна и задачи не переносит. Сдвиг плавный, 300 мс, с замедлением в начале и в конце. В этот жест входят все окна задач в видимом порядке: сначала прокручиваемые вкладки, в конце встроенные «Запланированные». Группы другого типа этот жест не пропускает. Экран настроек свайпом не открывается.

При запуске открывается первое окно в порядке сортировки.

## 6. Экран списка

Сверху вниз:

1. Полоса навигации. Названия групп, иконка часов и шестерёнка стоят в одной строке и на одной вертикали. Часы и шестерёнка — контурные значки, как тонкое кольцо с циферблатом и тонкая шестерёнка, без заливки круга.
2. Кнопка «Добавить» на всю ширину, высота 48dp, отступы 16dp, скругление 16dp, заливка `#F0C674`, текст `#1A1408`, слева значок плюса.
3. Список облаков. Подписей «№», «Задача» и «Рейтинг» нет.

Шесть однострочных облаков помещаются на экран под кнопкой «Добавить» без прокрутки.

### 6.1. Облако задачи

Каждая задача — отдельная карточка одного рисунка:

- скруглённый прямоугольник, радиус 18dp, без волнистого края;
- заливка и кромка из раздела 3.1;
- высота по тексту: одна короткая строка даёт карточку около 52dp;
- зазор между карточками 6dp;
- поля внутри 12dp по горизонтали и 8dp по вертикали;
- тень 4dp.

Внутри слева направо: номер строки с 1, название, звёзды, красная корзина. Заголовков над этим рядом нет. Название в списке — 14sp. Если в базе больше 50 символов, на карточке видны первые 50 и многоточие. Эти 50 символов переносятся на следующие строки, карточка подрастает. В окне `SCHEDULED` под названием дата `дд.мм.гггг` и время `чч:мм`. Если задан повтор, третьей строкой мелко: `каждые N дн.`.

Подсветка включается, когда наступает минута срока: `dueUnseen` становится истиной. Повтор сдвигает дату и эту отметку не снимает, даже если новый срок уже в будущем. Снимает её только вход в напоминание из списка или из уведомления в шторке. Пока отметка стоит, карточка в списке залита `#4A2A24`, а не обычным `#1A2030`. Текст названия остаётся `#F6F3EC`. Строка даты — `#FF8D8D`. Время и повтор цветом не выделяются. На открытом экране в этот заход дата тоже подсвечена: текст поля `#FF8D8D`, фон поля `#4A2A24`. Поле времени обычное. После выхода в список карточка снова обычная. Если минута наступает, пока это напоминание уже открыто, дата на экране подсвечивается сразу, а в списке после выхода подсветки нет.

Рейтинг — ряд звёзд длиной `RatingScale.MAX`. Закрашены звёзды с первой по текущее значение, остальные — контур. Нажатие на N-ю звезду ставит рейтинг N. Ниже `RatingScale.MIN` опустить нельзя: повторное нажатие на уже выбранный минимум оставляет минимум. У новой задачи рейтинг равен `RatingScale.MIN`, пока человек не выбрал иное в форме.

Кнопка удаления справа: круг 36dp, заливка `#E5484D`, белая корзина. Нажатие удаляет задачу сразу, без вопроса, и показывает полосу «Вернуть» из раздела 6.4.

Пустой список: под заголовком текст «Пока нет задач» цветом `#B7B1A6`. Кнопка «Добавить» на месте.

### 6.2. Нажатия по задаче

- Короткое нажатие по карточке открывает редактирование. Нажатие по звёздам и по корзине карточку не открывает.
- Долгое нажатие поднимает карточку (чуть крупнее, тень сильнее) и включает перетаскивание в обычном списке и в созданной группе со сроком. Во встроенных «Запланированных» долгое нажатие карточку не поднимает: порядок там задаёт дата, ручная перестановка сбрасывается.
- Вертикальное перетаскивание плавно двигает облако вверх и вниз и меняет порядок. Облако влево и вправо не едет: по горизонтали оно остаётся в колонке списка. Номера строк пересчитываются сразу. Палец держит облако до отпускания, позиция записывается в базу в конце жеста. Во встроенных «Запланированных» вертикальный жест порядок не меняет.
- Горизонтальное движение пальца, пока облако поднято, меняет группу того же вида и не двигает само облако вбок. Чужие группы пропускаются. Новая группа появляется сразу, без плавного сдвига. Пример: слева направо стоят Сегодня, Неделя, Месяц, группа со сроком «Срочные» и обычный список «Год». Заметка из «Месяца» вправо попадает сразу в «Год», минуя «Срочные». Напоминание из «Срочных» вправо попадает во встроенные «Запланированные», минуя «Год».
- В обычном списке и в созданной группе со сроком облако остаётся под пальцем, и там же продолжается вертикальное перетаскивание: место в списке — там, где палец по вертикали, а не в конце. Жест не кончается на границе: пока палец не отпущен, можно перейти ещё в одну группу того же вида.
- Во встроенных «Запланированных» перенос сбрасывает ручной порядок. Напоминание встаёт по дате срабатывания, а не на высоте пальца. Пока палец над этим окном, вверх и вниз порядок не двигают. Если палец уходит дальше в созданную группу со сроком, вертикальное перетаскивание снова включается.
- С края групп своего вида список не перепрыгивает. Заметка не входит в группу со сроком, напоминание не входит в обычный список.

### 6.3. Порядок и новая строка

В обычном списке и в созданной группе со сроком новая запись встаёт в конец `sortOrder`.

Во встроенных «Запланированных» напоминания стоят по `nextFireAt` по возрастанию: ближайшее срабатывание сверху, более поздние ниже. При одинаковом моменте выше напоминание с меньшим id. Новое напоминание сразу встаёт на это место, ручной порядок не хранится. После переноса срока повтором строка сама занимает новое место, номера в колонке «№» пересчитываются. В созданной группе со сроком повтор обновляет дату в ячейке и строку с места не двигает.

После создания открывается группа, в которую заметку или напоминание сохранили. Новая строка на 3 секунды подсвечивается более светлым фоном: заливка `#2A3344` вместо `#1A2030`, кромка остаётся `#2C3340`, текст остаётся `#F6F3EC`. Затем за 300 мс фон возвращается к обычной заливке. Список за 350 мс плавно доскролливается так, чтобы эта строка была видна целиком, с отступом 8dp от края видимой области. Если она уже видна целиком, экран остаётся на месте и работает только подсветка.

### 6.4. Полоса «Вернуть»

Полоса приклеена к низу экрана и лежит поверх списка: прокрутка её не уносит. Отступы от краёв 16dp, высота 48dp, скругление 16dp. Слева текст: «Задача удалена» для одного объекта и «Удалено: N» для нескольких. Справа слово «Вернуть». Текст `#F6F3EC`.

Полоса одновременно кнопка и индикатор времени. Внутри её границ два фона. Нижний стоит на месте, цвет `#161B22`. Верхний в начале закрывает всю полосу, цвет `#3E4654`, и за 5 секунд уезжает влево. За границами полосы его не видно: открывается нижний фон справа налево. Нажатие в любое место полосы — это «Вернуть».

Каждое следующее удаление, пока полоса на экране, добавляет объект в тот же буфер, обновляет число N и заново заполняет верхний фон на всю ширину: 5 секунд считаются сначала. В буфере лежат все объекты этой серии, не только последний. «Вернуть» восстанавливает каждый на прежнее место: у заметки это прежняя позиция в списке, у напоминания — место по его дате. Будильник напоминания ставится снова. Если 5 секунд прошли без нажатия, полоса исчезает и буфер забывается. Новое удаление после этого начинает серию заново.

Удаление корзиной из открытой заметки закрывает её и открывает группу, где заметка лежала. Полоса «Вернуть» появляется уже на этом списке, по тем же правилам.

## 7. Создание и редактирование

Отдельный экран заметки или напоминания, не диалог. Сверху вниз: полоса навигации, затем шапка, затем поля.

Полоса навигации та же, что на списках. Ни одна вкладка и ни одна иконка не выделены. Нажатие на вкладку, иконку часов или шестерёнку закрывает этот экран без записи и открывает выбранную группу или настройки.

Шапка под полосой, высота 56dp:

- слева стрелка назад, 48dp, цвет `#F6F3EC`. Она закрывает экран без записи и возвращает в группу, из которой открыли форму. Если экран открыли из уведомления, возврат ведёт в группу этой заметки;
- по центру заголовок. Для обычной группы текст «Задача N». Для окна `SCHEDULED` текст «Напоминание N». N — порядковый номер в этой группе, с 1, тот же, что в колонке «№». У ещё не сохранённой заметки N — следующее место внизу выбранной группы. У ещё не сохранённого напоминания N — место, которое оно займёт по уже введённым дате и времени среди текущих напоминаний. Пока срок не распознан, заголовок без номера: «Напоминание». У заметки смена группы в списке сразу меняет номер. У напоминания номер меняется вместе со сроком;
- справа иконка корзины, 48dp, цвет `#E5484D`. У сохранённой заметки она удаляет её сразу и выбрасывает в группу, где заметка лежала. На этом списке появляется полоса «Вернуть» из раздела 6.4. У ещё не сохранённой корзина просто закрывает экран без записи и полосу не показывает.

Свайп от левого края экрана делает то же, что стрелка назад: закрывает экран без записи. Этот свайп не листает группы.

Поля сверху вниз:

1. Название. Обязательное. До 500 символов. Поле начинается с одной строки и растёт вниз по мере ввода. В списке из него видны только первые 50 символов, дальше многоточие.
2. Группа. Выпадающий список. У заметки в нём только обычные окна, без групп со сроком. У напоминания только группы со сроком, включая встроенные «Запланированные», в порядке навигации. При создании уже выбрано окно, которое было открыто. При редактировании выбрано окно этой записи. Список можно сменить.
3. Описание. Отдельный блок на экране заметки и на экране напоминания. Несколько строк, можно оставить пустым. До 5000 символов. В тексте распознаются ссылки `http://` и `https://` до пробела. Такая ссылка рисуется цветом `#7EB6FF` и подчёркивается. Нажатие по ней открывает адрес внешней программой телефона, само приложение страницу не загружает и разрешение `INTERNET` из-за этого не появляется. Нажатие по остальному тексту ставит курсор и даёт править описание. Если ссылку открыть нечем, под блоком на 3 секунды виден текст «Нечем открыть ссылку», экран заметки остаётся открытым.
4. Рейтинг. Обязательное. Тот же ряд звёзд, что на карточке: длина `RatingScale.MAX`, нажатие на N-ю звезду ставит значение N, ниже `RatingScale.MIN` не опускается. При создании уже выбрана `RatingScale.MIN`. При редактировании показано сохранённое значение.
5. Блок срока. Есть только на экране напоминания. На экране заметки его нет.
6. Кнопка на всю ширину. При создании подпись «Добавить». При редактировании подпись «Сохранить». Стиль тот же, что у «Добавить» на списке.

Блок срока, сверху вниз:

- Дата. Слева и справа от поля небольшие стрелки, само поле и кнопка календаря между ними. Формат `дд.мм.гггг`. Календарь — системный диалог Material 3, дни раньше сегодняшнего в нём не выбираются. Выбор в календаре подставляет текст в поле, ручная правка тоже допустима. Правая стрелка прибавляет 1 день и время не трогает. Левая убавляет 1 день, только если получившийся момент не раньше текущей минуты. Иначе левая стрелка тусклая, цвет `#8E887F`, и нажатие ничего не меняет. Активная стрелка цвета `#F6F3EC`, рисунок около 24dp, область нажатия 48dp.
- Время. Такой же ряд: левая стрелка, поле, кнопка часов, правая стрелка. Формат 24 часа `чч:мм`. Диалог времени в 24-часовом виде. Поле и диалог показывают одно и то же значение. Правая стрелка прибавляет 1 час и ставит минуты в 00. Если час переходит за полночь, дата становится следующим днём, время `00:00`. Левая стрелка убавляет 1 час и тоже ставит минуты в 00, пока результат не раньше чем через 2 минуты от текущей минуты. Если такой шаг уже ближе, поле становится ровно этим ближайшим допустимым моментом: текущая минута плюс 2 минуты, с её минутами, и левая стрелка тускнеет и перестаёт нажиматься. Стартовое значение «плюс час» на этот расчёт не влияет. Пример: сейчас 15:31, ближайший допустимый момент 15:33. В поле 17:00. Нажатие влево даёт 16:00. Ещё одно влево даёт 15:33, и левая стрелка неактивна.

При создании напоминания дата — сегодняшняя, время — текущее плюс 1 час, минуты те же. Если этот час переходит за полночь, дата — завтра, время — остаток после полуночи. Левая стрелка даты неактивна, когда шаг на день назад был бы раньше текущей минуты. Левая стрелка часа при стартовом значении обычно активна: одно нажатие влево ставит ближайший допустимый момент, если час с минутами 00 уже ближе чем через 2 минуты.
- Повтор. Необязательное число дней, других периодов нет. Поле узкое, по ширине трёх цифр, около 72dp, и стоит у левого края, а не на всю строку. Справа от него подпись «дн.». Клавиатура цифровая, в поле помещается не больше трёх символов. Подсказка в поле: «5». Подпись под полем: «Пусто — один раз. Число — уведомление каждые N дней в это время, начиная с указанной даты.» Допустимый диапазон берётся из `RepeatDays`: `MIN = 1`, `MAX = 999`.

Проверки перед записью. Ошибки пишутся под полями, экран не закрывается:

- пустое название;
- рейтинг вне диапазона `RatingScale.MIN`…`RatingScale.MAX`;
- для напоминания: пустая или неразборчивая дата, несуществующий день, пустое или неразборчивое время;
- для напоминания: человек сам ввёл момент раньше чем через 2 минуты от текущей. Самое раннее допустимое — текущая минута плюс 2 минуты. Если сейчас 15:31, записать можно 15:33 и позже. Текст ошибки: «Минимальный зазор — 1 минута»;
- повтор: если поле заполнено, это целое от `RepeatDays.MIN` до `RepeatDays.MAX`, сейчас от 1 до 999. Ноль, дробь и число длиннее трёх цифр не сохраняются.

Дата и время для напоминания обязательны оба. Пока хотя бы одно из них пустое или не разобрано, «Добавить» и «Сохранить» запись не создают и не меняют список: строки в окне `SCHEDULED` без срока не бывает. Ошибки остаются под полями, экран формы не закрывается.

Прошедшие дату и время стрелками и календарём указать нельзя. Ручной ввод момента раньше чем через 2 минуты не записывается, под полем текст «Минимальный зазор — 1 минута». Если момент был допустим в ту минуту, когда его поставили, а пока форма открыта текущее время подошло ближе чем на 2 минуты, «Добавить» и «Сохранить» ошибку не показывают: в запись пишется текущая минута плюс 2 минуты.

Смена группы у заметки переносит её в выбранный обычный список и ставит в конец этого списка. Срок у заметки не появляется. Смена группы у напоминания переносит его в выбранную группу со сроком. Во встроенных «Запланированных» оно встаёт по дате. В созданной группе со сроком — в конец списка.

Системная кнопка назад закрывает экран без записи, как стрелка и свайп от левого края. После создания открывается группа, в которую запись сохранили, и срабатывают подсветка и прокрутка из раздела 6.3. После правки открывается та же группа. Подсветка новой строки при правке не включается.

## 8. Настройки

Экран открывается кнопкой-шестерёнкой. Свайпом не открывается.

Сверху знак и слово Tasks, под ними подпись «Задачник».

Дальше раздел «Окна». В нём текущие окна задач, без пункта «Настройки».

Строка окна, которое можно переставлять: ручка перетаскивания, название, мелкая подпись «Заметки» или «Напоминания». У группы со сроком перед названием та же иконка часов, что в навигации. Долгое нажатие и перетаскивание за ручку меняют порядок этих окон. Этот порядок — порядок прокручиваемых вкладок. Встроенные «Запланированные» ручки не имеют и стоят в полосе справа. «Настройки» в этом списке нет.

Короткое нажатие по названию открывает диалог с одним полем и кнопками «Отмена» и «Сохранить». Пустое имя и имя, которое уже занято другим окном без учёта регистра, не сохраняются. Вид окна при переименовании не меняется.

Под списком имя нового окна, выбор вида и кнопка «Добавить окно». Вид выбирается при создании и дальше не переключается: «Заметки» или «Напоминания». Новое окно встаёт в конец прокручиваемых вкладок. Имя по тем же правилам. «Напоминания» создаёт окно `SCHEDULED`: у задач будут дата, время и уведомление, в навигации перед именем появятся часы. Порядок в такой группе ручной, не как во встроенных «Запланированных».

У окна с `builtIn = false` справа красная корзина. Нажатие спрашивает: «Удалить окно „…“ вместе с задачами?». Подтверждение удаляет окно и его задачи и снимает их будильники. Исходные четыре окна корзины не имеют. «Сегодня», «Неделю» и «Месяц» можно переименовать и переставить. «Запланированные» можно переименовать, место иконки справа от этого не меняется, вид `SCHEDULED` сохраняется.

Если пользователь удалил или переименовал окна и сейчас смотрит настройки, возврат назад открывает прежнее окно, если оно ещё есть, иначе первое в списке.

Ниже раздела «Окна» две строки без кнопок и переключателей. Нажатие по ним ничего не открывает.

- «Язык», справа текст «Русский».
- «Тема», справа текст «Тёмная».

Значения читаются из тех же ресурсов, что и остальной интерфейс, чтобы позже их можно было сменить в одном месте.

## 9. Уведомления

Уведомления только локальные. Приложение само показывает их в шторке телефона. Внешней отправки нет.

Канал один: «Срок задачи», важность высокая, звук и вибрация по умолчанию канала.

В момент `nextFireAt` телефон показывает отдельное уведомление на каждую заметку. Несколько напоминаний на одно время не склеиваются в одну запись шторки: у каждого своё уведомление. У каждой записи:

- заголовок — название задачи;
- текст — описание, если оно есть, иначе «Подошёл срок»;
- нажатие открывает приложение сразу на экране этой заметки, с шапкой «Напоминание N». Соседние уведомления остаются в шторке.

Дальше:

- без повтора: будильник больше не ставится, задача в списке остаётся;
- с повтором: `nextFireAt` увеличивается на N дней (время суток то же), в ячейке виден новый срок, ставится следующий будильник. Во встроенных «Запланированных» строка встаёт на место по новой дате. В созданной группе со сроком остаётся там, куда её поставили.

Если телефон был выключен и момент уже прошёл, при следующей загрузке системы или запуске приложения пропущенные повторы пачкой не показываются. Считается ближайшее будущее время тем же шагом, оно записывается в задачу и на него ставится один будильник.

Точный будильник запрашивается через `SCHEDULE_EXACT_ALARM`. На Android 13 и новее отдельно запрашивается показ уведомлений. Если человек отказал, задача всё равно сохраняется. На экране окна `SCHEDULED` под кнопкой «Добавить» видна полоса: «Уведомления выключены» или «Точные будильники выключены» и кнопка «Открыть настройки», которая ведёт в настройки приложения или в экран точных будильников.

Пока разрешение не выдано, будильник не ставится. Когда разрешение появляется, при следующем входе в приложение будущие сроки ставятся в очередь снова.

Удаление задачи, снятие срока и удаление приложения отменяют будильник.

| Жест | Результат |

| Свайп влево или вправо по списку | плавный переход в соседнее окно |
| Короткое нажатие на карточку | редактирование |
| Короткое нажатие на звёзды | рейтинг становится равен номеру нажатой звезды, не ниже минимума |
| Короткое нажатие на красный круг | удаление с возможностью вернуть |
| Долгое нажатие на карточку обычного списка или созданной группы со сроком | поднять и перетаскивать |

| Влево или вправо с поднятой карточкой | сразу открывается следующая группа того же вида, чужие группы пропускаются. Облако остаётся под пальцем. В созданной группе продолжается вертикальное перетаскивание. Во встроенных «Запланированных» ручной порядок сбрасывается, место задаёт дата |

Свайп окна не начинается на кнопке «Добавить», на корзине, на звёздах и на полосе навигации.

Два горизонтальных жеста одновременно не срабатывают. Палец провёл в сторону без долгого нажатия — листается окно, задачи остаются в своих списках. Долгое нажатие в обычном списке и в созданной группе со сроком сначала поднимает карточку. Дальше палец двигает её только вверх и вниз, плавно, внутри колонки списка. Движение пальца влево или вправо открывает следующую группу того же вида и пропускает группы другого вида. Облако по горизонтали не едет. В новой созданной группе перетаскивание продолжается на высоте пальца. Во встроенных «Запланированных» карточка встаёт по дате, ручной порядок сбрасывается. Пока карточка поднята, плавное листание окна не включается. Короткое нажатие без движения открывает редактирование и ничего не переносит.

## 11. Состав проекта

Пакет `com.tasks.notebook`.

Ориентир по папкам, имена файлов можно уточнять, границы слоёв — нет:

- `MainActivity` — единственная точка входа, тёмная тема, edge-to-edge;
- `data` — сущности Room, DAO, база, начальное заполнение окон;
- `notifications` — канал, постановка и снятие будильника, приёмник загрузки телефона, открытие задачи из уведомления;
- `ui/list` — навигация, кнопка добавления, облака, жесты;
- `ui/edit` — создание и редактирование;
- `ui/settings` — окна;
- `ui/theme` — единственная палитра, шрифт, форма облака. Экраны берут цвета отсюда;
- `res/values/strings.xml` — все подписи по-русски. Код не хранит строки интерфейса сам;
- `RatingScale` — единственное место, где заданы минимум и максимум звёзд. Сейчас `MIN = 1`, `MAX = 3`. Карточка, форма и проверка читают эти две константы. Числа 1 и 3 в экранах не повторяются. Чтобы шкала стала длиннее или короче, меняются только они;
- `RepeatDays` — единственное место, где заданы границы повтора в днях. Сейчас `MIN = 1`, `MAX = 999`. Проверка поля и ограничение в три цифры читают эти константы;
- `res/mipmap` и вектор значка — логотип из раздела 3.3;
- `SETUP.md` в корне репозитория — раздел 12.

Экран настроек не содержит пунктов про сеть, аккаунт и резервное копирование. Строки «Язык» и «Тема» показывают текущие значения текстом.

## 12. Файл `SETUP.md`

Этот файл пишет разработчик вместе с приложением. Он на русском и содержит только то, что человек делает сам, без кода и без описания внутренностей.

Обязательные разделы:

1. Поставить Android Studio актуальной стабильной версии.
2. Открыть папку проекта и дождаться окончания синхронизации Gradle.
3. Включить на телефоне отладку по USB и разрешить её в окне телефона либо создать эмулятор в Device Manager.
4. Нажать Run и дождаться значка Tasks на устройстве.
5. При запросе разрешить уведомления.
6. При запросе разрешить точные будильники. Если система не спросила, указать путь: настройки телефона → приложения → Tasks → будильники и напоминания (формулировка зависит от производителя).
7. Где лежат данные: только внутри приложения. Удаление приложения удаляет задачи. Отдельного экспорта нет.
8. Как проверить уведомление: открыть «Запланированные», создать задачу на время через две минуты, свернуть приложение, дождаться уведомления, нажать его и убедиться, что открылась эта задача.
9. Прямо сказать, что аккаунт и интернет не нужны: запись в шторку показывает само приложение.

## 13. Приёмка

Сборка устанавливается на телефон или эмулятор с API 26 и новее. В манифесте нет `INTERNET`.

Дальше по шагам:

- после установки слева видны окна «Сегодня», «Неделя», «Месяц», справа приклеены иконка часов и иконка настроек; при прокрутке вкладок эта пара остаётся на месте;
- в полосе выделен ровно один пункт, и это то окно, которое открыто; после свайпа и после нажатия на другой пункт выделение переезжает на него;
- «Добавить» в обычном списке и в созданной группе со сроком ставит запись вниз; во встроенных «Запланированных» без даты или без времени строка не создаётся, с заполненным сроком она встаёт по ближайшей дате; в обоих случаях удачного создания новая строка на 3 секунды светлеет фоном, и список плавно доезжает до неё, если её не было на экране;
- в форме есть рейтинг звёздами, у новой задачи выбрана одна звезда, больше трёх выбрать нельзя, пока в `RatingScale` не изменён максимум;
- пустое название не сохраняется;
- описание можно не заполнять; ссылка `https://` в описании открывается внешней программой по нажатию;
- у новой заметки и у нового напоминания группа выбирается из списка своего вида, уже открытое окно выбрано заранее;
- на экране заметки полоса навигации на месте и ни один пункт не выделен; шапка показывает «Задача N» или «Напоминание N» с номером в группе; стрелка, системная назад и свайп от левого края закрывают экран без записи; корзина удаляет сохранённую заметку;
- нажатие на пункт навигации с этого экрана открывает выбранную группу;
- короткое нажатие открывает ту же задачу, «Сохранить» записывает правки;
- долгое нажатие в обычном списке и в созданной группе со сроком меняет порядок; во встроенных «Запланированных» долгое нажатие порядок не меняет;
- свайп по списку перелистывает окна плавно, в том числе открывает «Запланированные», список влево-вправо не ездит;
- на карточке нет подписей колонок; название длиннее 50 символов заканчивается многоточием; в форме поле названия растёт вниз и принимает до 500 символов;
- шесть однострочных карточек видны на экране без прокрутки;
- свайп с поднятой заметкой из «Месяца» вправо, если дальше стоят группа со сроком и обычный «Год», открывает «Год» и пропускает группу со сроком; облако остаётся под пальцем;
- свайп с поднятым напоминанием идёт только по группам со сроком; во встроенных «Запланированных» оно встаёт по дате, в созданной группе его можно двигать вверх и вниз;
- красная кнопка удаляет сразу; полоса «Вернуть» приклеена внизу поверх списка, её верхний фон за 5 секунд уезжает влево внутри границ; три удаления подряд держат в памяти все три объекта, фон заполняется заново и «Вернуть» возвращает все три на прежние места;
- корзина в открытой заметке закрывает её, открывает группу и показывает ту же полосу;
- в настройках новое окно создаётся как «Заметки» или «Напоминания»; у группы напоминаний в навигации перед именем стоят часы; «Запланированные» и «Настройки» с места не двигаются;
- после наступления срока карточка остаётся с фоном `#4A2A24` и красной датой, даже если повтор уже поставил новую дату; открытие из списка или из шторки показывает подсвеченную дату внутри, а после выхода список снова обычный;
- в настройках строки «Язык» и «Тема» показывают «Русский» и «Тёмная» текстом, без переключателей;
- исходные окна не удаляются, своё окно удаляется вместе с задачами после подтверждения;
- у задачи в «Запланированных» в одной ячейке две строки: дата и время;
- у нового напоминания стоят сегодняшняя дата и время на час позже текущего; стрелка часа влево не опускает момент ближе чем на 2 минуты и в конце ставит текущую минуту плюс 2;
- свой ввод слишком близкого времени показывает «Минимальный зазор — 1 минута»; если близким время стало, пока форма была открыта, сохранение само ставит текущую минуту плюс 2 минуты и ошибку не показывает;
- пустой повтор срабатывает один раз;
- повтор 5 ставит следующее уведомление через 5 дней на то же время, дата в ячейке обновляется;
- поле повтора узкое, под три цифры; 0 и 1000 не сохраняются;
- два напоминания на одно время дают две отдельные записи в шторке; нажатие открывает именно эту заметку, вторая запись остаётся;
- перезагрузка телефона не забывает будущий срок;
- отказ в уведомлениях не мешает сохранить задачу и показывает полосу со ссылкой в настройки;
- текст, «Добавить» и красное удаление явно отличаются от фона;
- на значке приложения список из трёх пунктов: верхний с галочкой, два нижних пустые. Облака на значке нет. Имя под значком — Tasks.
