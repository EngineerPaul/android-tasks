# Как запустить Tasks

Приложение ставится на телефон с Android 8 или новее. Аккаунт не нужен. Интернет не нужен: запись в шторку показывает само приложение.

## 1. Android Studio

Поставьте актуальную стабильную Android Studio с сайта разработчика Android.

## 2. Открыть проект

В Android Studio выберите Open и укажите папку `app` внутри этой папки Tasks (там лежит `gradlew`). Дождитесь, пока синхронизация Gradle закончится сама. Ничего дополнительно подключать не нужно.

## 3. Телефон или эмулятор

На телефоне включите режим разработчика и отладку по USB, подключите кабель и разрешите отладку в окне на телефоне.

Либо в Android Studio откройте Device Manager и создайте виртуальное устройство с Android 8 или новее.

## 4. Запуск

Нажмите Run и дождитесь значка Tasks на устройстве.

Готовый файл для установки без кабеля лежит после сборки здесь:

`app\app\build\outputs\apk\debug\app-debug.apk`

Скопируйте этот файл на телефон и откройте его. Если система пишет, что установка запрещена, разрешите установку из этого источника. Если телефон отказывается обновить уже стоящую Tasks, удалите старую Tasks и откройте файл снова.

## 5. Уведомления

При первом заходе в окно со сроком система спросит разрешение на уведомления. Разрешите его. Без этого будильник не ставится, а задача всё равно сохраняется.

## 6. Точные будильники

Если система спросит разрешение на точные будильники, разрешите его. Если не спросила, откройте настройки телефона → приложения → Tasks → будильники и напоминания (название пункта зависит от производителя) и включите их.

Пока разрешение выключено, на экранах со сроком видна строка со ссылкой в эти настройки.

## 7. Где лежат задачи

Только внутри приложения на этом телефоне. Удаление приложения удаляет задачи. Отдельного экспорта нет.

## 8. Проверка уведомления

Откройте «Запланированные», создайте задачу на время через две минуты, сверните приложение и дождитесь уведомления. Нажмите его: должна открыться эта задача.
